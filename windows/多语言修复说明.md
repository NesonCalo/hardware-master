# 硬件管理大师 1.1.0 — 多语言显示修复说明（2026-11-24）

## 交付物

- 主程序：`dist\HardwareMaster.exe`（单文件，约 31.9 MB，18:29 构建，含本轮全部修复）

## 修复内容

### 1. 翻译缺键不再回退中文（根因）
以前 `T()` 查不到译文就直接返回中文原句。现在：
- 非中文界面下，本语言缺译时回退 **英文**（`en.json` 作为兜底同时加载），绝不出现中文。
- 中文界面（zh-CN / zh-TW / zh-HK）仍走原逻辑。

### 2. 后端/系统返回的名称改为双语
界面上的中文很多不是文案，而是操作系统与传感器库给的名字：
- **温度 / 功耗 / 风扇传感器名**：CPU 封装 (Tctl/Tdie)、GPU 热点、显存、机箱风扇、GPU 风扇、核心 #1… 全部补英文标签（CPU Package、GPU Hot Spot、VRAM、Case Fan…）。
- **驱动页**：设备类名（系统设备 / USB 设备 / 人机接口…）、状态（设备已被驱动程序停止…）、厂商（(标准系统设备)…）、通用设备名、Windows 版本（Windows 11 专业工作站版 → Windows 11 Pro for Workstations）全部英文映射；搜索串也按英文匹配。
- **网卡名**：以太网 / 网络连接 2 / 蓝牙网络连接 2 → Ethernet / Network Connection 2 / Bluetooth Network Connection 2。
- **CSV 导出表头**：中文界面「时间」，其它语言「Time」。

### 3. 窗口与托盘
- 窗口标题、托盘悬浮提示、托盘菜单（打开主界面 / 退出）按当前语言切换，语言在设置里切换后立即生效。
- 程序启动时语言默认 **跟随系统**（`auto`），识别不到则英文。

### 4. 驱动页搜索框占位符接入 i18n

### 5. 时间不再跟系统区域走（第二轮补修）
「上次读取 下午5:25:56」这类中文来自 `toLocaleTimeString()` 直接跟系统区域（中文 Windows 会给「上午 / 下午」）。
现在统一走 `fmtTime()`，显式按界面语言取格式且强制 24 小时制，英文界面显示 `Last read 18:31:21`，不会再冒中文。
