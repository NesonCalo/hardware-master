外观主题

默认跟随 Windows 系统的深色 / 浅色设置
配色方案 选择「跟随系统」时，Windows 切换到深色或浅色后界面会同步变化。

界面语言

共 25 种语言，含简繁中文（台湾 / 香港用词）
选择显示语言 切换后界面立即生效；各语言的技术名词以该语言的习惯译法为准。

窗口与后台

关闭窗口时如何处理
关闭窗口后最小化到托盘 开启后点 × 不退出程序：主窗口最小化到任务栏、托盘图标保持常显，后台继续采集；点托盘「打开主界面」或点任务栏图标即可唤回。

托盘图标在任务栏右下角，右键可「打开主界面」或「退出」；关闭此开关后，点 × 直接退出程序。

启动

写入当前用户启动项，无需管理员权限
开机自动启动 开启后写入 HKCU\Software\Microsoft\Windows\CurrentVersion\Run，登录 Windows 后自动启动。

想开机后不显示窗口，只需同时开启左侧「关闭窗口后最小化到托盘」。

文件与诊断

全部数据保存在本机

设置保存在 %APPDATA%\HardwareMaster\settings.json，日志在同目录的 app.log。
