## 二、安装、启动与卸载

1. 双击 MSI → Windows 会弹一次 UAC（因为要写入 `C:\Program Files` 并登记计划任务），点“是”。
2. 向导会依次显示许可协议（该语言版本）、目标文件夹（默认 `C:\Program Files\NesonCalo\Hardware Master`）、开始安装、完成。
3. 安装完成后桌面和开始菜单会出现对应语言的快捷方式。**以后从快捷方式启动不再弹 UAC**：安装程序登记了一个名为 `NesonCalo HardwareMaster` 的计划任务，只有“手动启动”这一个动作、没有任何触发器、不会开机自启，运行身份是你本人、权限级别为“最高”，所以程序以管理员身份起来时不经过 UAC 提示。
4. 卸载：设置 → 应用 → 已安装的应用里找到对应名称卸载，或 `msiexec /x` 对应 MSI。卸载会删除安装目录、计划任务、桌面与开始菜单快捷方式、注册表项；只保留你自己的 `%APPDATA%\HardwareMaster`（设置与日志），需要的话可手动删除。

## 三、非流氓行为说明

- 不写开机自启（除非你在程序设置里自己打开）、不装常驻服务、不捆绑任何第三方软件、不安静默升级、不做联网上报。
- 计划任务没有触发器，只在点快捷方式时被调用；卸载时由卸载程序删除。
- 采集与计算全部在本机完成，界面只绑定 `127.0.0.1` 的随机端口，不对外网开放。
- 安装程序未做代码签名，首次运行会有“未知发布者 / SmartScreen”提示，属正常现象：点“更多信息 → 仍要运行”。

## 四、几点须知

- 25 个包共用同一个升级码，同一版本安装另一个语言包会**替换**当前已装的那一份（不会叠加两份）。
- 德语、意大利语的应用显示名与英语一致（都是 Hardware Master），这是产品名在该语言下的通用写法。
- 孟加拉语、波斯语、印地语这几个 WiX 官方未提供向导翻译的语言，主流程（欢迎、许可、目录、安装、进度、完成、卸载维护）已本地化；极少数故障类对话框（如文件占用、磁盘不足、错误详情）仍显示英文文案。
- 老的 `installer\输出\硬件管理大师-安装程序-1.1.0.exe`（Inno 版）已经被这一批 MSI 取代，留作对照；`installer\硬件管理大师.iss` 等 Inno 脚本仅作参考。

## 五、从源码重新打包

```powershell
python installer\msi\build_msi.py --all          # 全部 25 个语言
python installer\msi\build_msi.py --lang zh-CN   # 单个语言
```

依赖：WiX 3.14 便携工具链（`candle.exe`、`light.exe`、`WixUIExtension.dll`）、已构建的 `dist\HardwareMaster.exe`、`app\ui\locales\*.json`。构建脚本会按语言生成 `loc.wxl`、`license.rtf`、`setup-task.ps1` 与 `product.wxs`，再调用 WiX 编译。
