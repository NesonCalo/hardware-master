安装前请了解这几点（本程序不做的事也写在这里）

1. 安装会做哪些事
   - 复制程序到 Program Files\NesonCalo\Hardware Master，写入开始菜单（可选桌面快捷方式）与标准卸载信息。
   - 登记一个名为 “NesonCalo HardwareMaster” 的 Windows 计划任务：只用于“手动以管理员权限启动主程序”，不设任何触发器，不随开机/登录自动运行。
   - 这样双击快捷方式时不再弹 UAC 授权框，直接以管理员模式打开（硬件传感器需要管理员权限才能读全）。

2. 不做什么（拒绝流氓行为）
   - 不写入开机自启项、不常驻后台、不自动更新、不联网上传任何数据。
   - 不捆绑任何第三方软件、不修改浏览器主页/搜索、不弹广告、不安装服务。
   - 安装目录与注册表项均可通过“设置 → 应用 → 硬件管理大师 → 卸载”干净移除；卸载同时删除上面的计划任务。

3. 卸载
   - 卸载后计划任务、Program Files 目录、快捷方式与卸载信息都会被清除；仅保留你自己的设置与日志（%APPDATA%\HardwareMaster），可手动删除。

4. 便携版
   - 同一份程序也有单文件便携版，无需安装、不创建计划任务；便携版启动时若需要管理员权限，会按设置询问一次（可在设置页关闭自动提权）。

继续安装即表示你已阅读并同意随附的服务条款。
