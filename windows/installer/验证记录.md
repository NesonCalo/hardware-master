# 安装程序验证记录（2026-11-24）

在 DESKTOP-4HTSMG0（Windows 11，UAC 开启：EnableLUA=1、ConsentPromptBehaviorAdmin=5）实机验证：

1. **静默安装**（`/silent /desktopicon`）：安装到 `C:\Program Files\NesonCalo\Hardware Master`，日志 `Installation process succeeded`，随后 `elevation task registered: NesonCalo HardwareMaster`。
2. **计划任务属性**：`RunLevel=Highest`、`LogonType=Interactive`、`UserId=NesonCalo`、**Triggers=0**、`MultipleInstances=IgnoreNew`、`ExecutionTimeLimit=PT0S`，动作指向安装目录 exe。
3. **免 UAC 启动**：以普通（非管理员）身份运行安装目录 exe，进程自身退出，日志出现
   `已通过安装版计划任务以管理员权限启动（无 UAC 提示）` → `启动：admin=True`，窗口与托盘正常，全程没有 UAC 允许框。
4. **卸载**（`/SILENT /SUPPRESSMSGBOXES`）：安装目录、`NesonCalo HardwareMaster` 计划任务、开始菜单与公共桌面快捷方式、卸载注册项全部移除；仅保留用户自己的 `%APPDATA%\HardwareMaster` 设置与日志。
5. **不写开机自启**：`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下无 `HardwareMaster` 项；计划任务无任何触发器。
6. **单实例**：第二次双击会唤回已有窗口后退出（日志 `已有实例在运行，唤回主窗口后退出`），不再起第二个进程。
